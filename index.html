The Portfolio of Jordan Barden

Project 1

  • The Legend of Zelda (Unity Remaster)
  • This game began as a two person class project that would take approximately a month; however, my partner had to drop the class 9 days into the project. They were able to make the initial system for swinging the sword and debug system to destroy enemies on hit, but I completed the rest of the systems myself. These systems include, character movement, basic AI, equipment, room transitioning, inventory, sound, and graphics.
  • I did not create most of the initial map, art, or sound. The initial map for the dungeon 1 was provided to me from the class, art and sound was aquired from thevgresource website, and the background music was taken from videogame music preservation foundation.
  • The technology used in this project include, unity 2022.3.43f1, 2019 Microsoft Visual Studio, github desktop + github, and the programming language C Sharp.

Project 2

  • Telekinetic Blue Circle Vs The Angry Purple Diamonds
  • This game was a single person assignment that I had to both design and build over 2 weeks. The premise of the game is what if you had telekinetic powers to throw projectiles back at enemies. This premise was inspired from: Star Wars: The Force Awakens, Dead Space, and Legend of Zelda Tears of the Kingdom.
  • I created all art and most systems in the game. The systems I did make include grabbing/throwing enemies, health and UI, general movement, and basic ai for the enemies. The systems I did not create were an event bus (provided as part of the class project), Unity Input System, and the Unity Cinemachine Package. Additionally, all sounds were taken from FreeSound.org.
  • The technology used in this project include, unity 2022.3.43f1, 2019 Microsoft Visual Studio, github desktop + github, and the programming language C Sharp.

Project 3

  • Endless Deadlines
  • This game was a 5 person assignment that I helped design and build over 7 weeks. The premise of the game is you are scared of the dark and must use lights to prevent you from passing out from fear. This premise was inspired from the game Soma and the fear of the dark.
  • The systems I made include movement, the lights and there effects, and a scrapped inventory system (no longer available to see). The systems I did not create were an event bus (provided as part of the class project) and the Unity Cinemachine Package.
  • The technology used in this project include, unity 2022.3.43f1, 2019 Microsoft Visual Studio, github desktop + github, a unity editor script from https://github.com/Lumos-Github/Auto-add-Shadow-Caster-2D-on-TileMap/issues ,and the programming language C Sharp.
