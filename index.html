Custom 2D Game Engine

  • My game engine was developed as a 4 month class project. It supports the platforms Windows, Linux, and Mac. Users can script the game in lua, render to the screen with SDL, and use box2D for physics.
  • As part of the class, we had to make a custom feature for our engine to differentiate it from the class's design. I chose a custom sprite renderer c++ component. The class originally gave the user the ability to directly draw to the screen through a function call. This provided alot of flexibility to the user, but sacrificed performance. Specifically, all function calls had to cross from lua to c++ and store the request before we knew the size of the screen each frame. My implementation originally did not support removing draw calls from the request queue after the size of the screen was established either. Because of these performance sacrifices, I decided I wanted to make a custom data oriented design render framework. In my design, all the data is cached and only modified if the component has associated functions called. Additionally, I collect all draw calls after lua finishes running, so I am able to determine if an image is on screen before I save and sorts its data. Finally, my framework structure stores the vectors of data into objects called layers. These layers can be adjusted to render either on screen space or world space, and each layer can have its render sorting be disabled for improved performance.
  • Custom Feature Demonstration
  • The technology used in this project include C++ 17, Lua 5.4.6, RapidJSON 1.1.0, GLM 0.9.9.8, LuaBridge 2.7.207, SDL 2.28.5, SDL_image 2.6.3, SDL_ttf 2.20.2, SDL_mixer 2.6.3, Box2D 2.41, 2022 Microsoft Visual Studio, XCode, ubuntu for linux, and github desktop + github.

Game 2

  • Telekinetic Blue Circle Vs The Angry Purple Diamonds
  • This game was a single person assignment that I had to both design and build over 2 weeks. The premise of the game is what if you had telekinetic powers to throw projectiles back at enemies. This premise was inspired from: Star Wars: The Force Awakens, Dead Space, and Legend of Zelda Tears of the Kingdom.

The systems I did not create were an event bus (provided as part of the class project), Unity Input System, and the Unity Cinemachine Package. Additionally, all sounds were taken from FreeSound.org.
  • The technology used in this project include, unity 2022.3.43f1, 2019 Microsoft Visual Studio, github desktop + github, and the programming language C Sharp.
